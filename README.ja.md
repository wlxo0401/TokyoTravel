ビルドツール不要、GitHub Pages にデプロイする静的な旅行プラン Web アプリ。
**これを土台に、AI と一緒に自分だけの旅行プラン テンプレートを育ててください。**

> このリポジトリはひとつの**サンプル**です。データは 2026 年 9 月の東京旅行用に埋めてありますが、
> 決まりはありません。気に入ればそのまま使い、そうでなければ目的地・構成・デザイン・機能まで
> 好みに合わせて作り替え、より良いテンプレートにしてください。私たちは出発点にすぎません。

## なぜ作ったか

出発点はひとつの気づきです。**旅行前は一生懸命プランを立てるが、旅行中はプランを書き直さない。**
旅行は 100% 計画どおりには進まず変数も出ますが、旅の途中で行程表を作り直したりはしません。
そこでこのアプリは、プランニングを 2 つのフェーズに分けて考えます。

- **旅行前 — 計画**: AI と一緒に行程を組み、必要な情報（場所・リンク・候補）を先に入れておきます。
  GitHub に push すればすぐ公開。同行者にはリンクを共有するだけ。
- **旅行中 — 参照（読み取り専用）**: ここではプランを編集しません。準備した情報を
  **その場で確認し、素早く判断する**ためのものです。
  - 日付タブで今日の動線をひと目で
  - エリアごとの候補地をゆるいリストで見て現地で選ぶ（時刻表ではない）
  - ワンタップで地図の経路案内（韓国内は Naver、日本内は Google）
  - 行った場所はチェック（端末ローカルに保存）

プランは強制しません。決まった時刻表の代わりに「ゆるい順序＋候補リスト」を持ち、
現地でその都度選べばいい。それが旅というものです。

## 特徴

- フレームワーク・バンドラー・バックエンドなし。純粋な HTML/CSS/ES モジュール。
- データと画面が分離 — 旅行情報はすべて 1 つの `data/trip.js` に。
- ライトモード固定、モバイル優先（PC でも使用可）。

## はじめに

### 1. クローン & ローカル実行

```bash
git clone https://github.com/<your-name>/<your-repo>.git
cd <your-repo>
python3 -m http.server 8000
# http://localhost:8000
```

`index.html` をブラウザで直接開くと ES モジュールの読み込みができないため、必ずローカルサーバーで配信してください。
（`python3` の代わりに `npx serve` など、任意の静的サーバーで可）

### 2. 自分の旅行に変える

いちばん速いのは **AI に任せること**です。リポジトリ全体を開いて
「このプロジェクトを ○○ 旅行に合わせて修正して」と言えば、`data/trip.js` を中心に、
必要なら画面・タブ構成・スタイルまで一緒に手を入れてくれます。

このリポジトリの AI 向け作業ルールは [`CLAUDE.md`](CLAUDE.md) にあります — Claude Code は
自動で読み込みます。他のツールにはこのファイルをルールとして参照させてください。

### 3. デプロイ（GitHub Pages）

1. リポジトリ → **Settings → Pages**
2. **Source: Deploy from a branch**、Branch: `main` / `/(root)`
3. 数分後に `https://<your-name>.github.io/<your-repo>/` で公開
4. そのリンクを同行者に共有。以降は変更を push するだけで自動反映されます。

`.nojekyll` ファイルが Jekyll 処理をスキップします。アセットのパスはすべて相対パスなので、サブパス配信でも動作します。

## 注意

> [!WARNING]
> **予約番号や個人情報を直接入力しないでください。** `data/trip.js` はリポジトリに
> コミットされ、GitHub Pages で一般公開されます。あとで削除しても git 履歴に残ります。
> 予約番号、パスポート・身分証番号、電話番号、自宅の詳細住所、ドアの暗証番号などは
> 入れず、同行者とは非公開のチャネルで共有してください。場所の名前・エリア・地図の
> 座標くらいは問題ありません。
